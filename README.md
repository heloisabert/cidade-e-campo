# cidade-e-campo#

Este projeto é uma celebração da conexão entre o campo e a cidade, dois mundos aparentemente diferentes, mas que se complementam e interagem de várias maneiras. O site apresenta uma visão do campo como espaço de tranquilidade e origem da produção agrícola, e da cidade como um centro dinâmico de oportunidades e inovação.

## Objetivo

O objetivo do projeto é criar uma reflexão visual sobre como a vida rural e urbana estão interligadas, desde a alimentação até as trocas culturais.
